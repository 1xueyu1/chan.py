# 回测口径说明

## 基本原则

本项目回测必须模拟实时可见信息。标签可以用于训练，但不能在交易决策中直接读取。

## 时间口径

- 入场时间必须是信号可用时间。
- 不默认额外推迟 15m。
- 多周期特征只能使用当时已经闭合的 K 线。
- walk-forward 中测试年份不得参与训练。

## 交易口径

- 当前主线使用币安合约市场数据。
- 入场信号来自 15m 二类买卖点族群。
- 出场使用 `family_realtime` 状态机。
- 第三段确认后等待 15m 同级别任意反向买卖点出场。
- 结构失效、成本保护、极端风险保护必须基于实时可见价格。

## 结果统计

每次正式 walk-forward 至少输出：

- 总交易数。
- 每年交易数。
- 胜率。
- 收益。
- Profit Factor。
- 最大回撤。
- 每个实时路径的交易贡献。
- 每币种表现。
- 与基准版本的差异。

## 禁止事项

- 禁止用未来路径标签直接决定出场。
- 禁止只报告收益，不报告交易数和回撤。
- 禁止只跑单一年份就判断实验有效。
- 禁止把 smoke 结果作为正式结果。
- 禁止在未记录口径变化的情况下对比不同版本。
