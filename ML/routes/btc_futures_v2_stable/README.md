# BTC 合约稳定性路线：`btc_futures_v2_stable`

这条路线不覆盖 `btc_futures_v1`。它的目标不是追求单次回测收益，而是解决 v1 暴露出的核心问题：跨年份不稳定、阈值为了频率放进低质量信号、概率未校准却被当成信心。

## 已实现内容

- ATR 自适应 1:1 标签：默认 `1.5 * 15m ATR%`，并限制在 `0.6%` 到 `1.8%`。
- 稳定特征筛选：剔除明显时间代理特征，按覆盖率、漂移和重要性选择特征。
- 一级买/卖模型：买点和卖点分开训练。
- 二级 gate：只有 gate 在验证集 AUC 达标且优于一级模型时才启用。
- 成本感知阈值：验证集必须满足最小胜率、正平均净收益和 PF 要求。
- 分市场状态 policy：验证不过的方向或市场状态直接禁用。
- 年度 walk-forward：默认最近两年验证，每个验证年都必须过线。

## 运行方式

```powershell
Scripts\btc_futures_v2_build_dataset.ps1 -Force
Scripts\btc_futures_v2_train.ps1 -ValidStart 2024-01-01 -TestStart 2026-01-01
Scripts\btc_futures_v2_backtest.ps1
Scripts\btc_futures_v2_walk_forward.ps1 -ValidationYears 2
```

## 当前结论

严格稳定性口径下，当前 BTC 缠论买卖点 + 现有特征只找到极少量高置信交易。

最终正式模型在 2024-2025 两年验证窗口下，要求验证胜率至少 65%、PF 至少 1.50：

- buy：禁用
- sell：禁用
- 2026 回测：0 笔交易，收益 0，回撤 0

年度 walk-forward：

| 测试年 | 交易数 | 收益 | 说明 |
|---:|---:|---:|---|
| 2024 | 25 | 1.14% | 高置信分组少量交易 |
| 2025 | 0 | 0.00% | 两年验证后无合格状态 |
| 2026 | 0 | 0.00% | 两年验证后无合格状态 |

相比 v1 在 walk-forward 中亏损约 69.6%，v2 严格版将结果改善为小幅正收益，但代价是交易频率极低。当前策略已经不会为了频率牺牲稳定性。

## 下一步真正需要解决的问题

当前特征和标签仍无法产生稳定正期望。后续应新增信息源，而不是继续调阈值：

- 更贴近缠论的中枢离开段、三买三卖有效性、背驰级别强度特征。
- 市场状态分层建模，而不是单模型覆盖所有年份。
- 更高周期趋势过滤，例如 4h / 1d 只做顺大级别方向。
- 引入成交量、资金费率、盘口或波动结构数据。
- 对不同 TP/SL 半径做 walk-forward 搜索，而不是固定一个 ATR 参数。
