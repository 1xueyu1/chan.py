# 当前基准：decision_realtime_v2

## 基准定义

```text
基准版本：decision_realtime_v2
模型路线：btc_futures_v2_bsp2_family
结果目录：result/btc_futures_v2_bsp2_family_wf_decision_realtime_v2
模型目录：result/ml/btc_futures_v2_bsp2_family_wf_decision_realtime_v2
```

该基准是后续所有实验的对照对象。任何新实验都必须说明相对该基准的变化。

## 核心口径

- 入场：15m 二类买卖点族群。
- 入场时间：信号可用时间，不额外推迟 15m。
- 出场：`family_realtime` 实时状态机。
- 第三段确认后：保留 15m 同级别任意反向买卖点 `opposite_bsp` 出场。
- 风险处理：结构风险定仓，而不是硬删除低质量信号。
- 禁止：回测决策直接读取未来标签。

## 保护项

以下逻辑是当前基准中已经验证有效的部分，后续实验不得随意改动：

1. 第三段确认后的 15m `opposite_bsp` 出场路径。
2. `bsp2_t3_overlap` 入场时视为第三段已确认的处理。
3. 用结构风险定仓压制确认前失效，而不是直接删信号。
4. 不使用旧概率硬过滤来压缩交易频率。

## 当前主要问题

后续实验应优先聚焦：

- `realtime_invalid_before_confirm` 仍是最大亏损来源。
- `weak_no_confirm` 的处理仍有优化空间。
- 二级模型对坏二类买卖点的区分能力仍需提高。
- 部分币种表现可能需要单独分析，但不能用事后收益筛选污染验证。
