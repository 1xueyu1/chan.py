# 实验 Spec 模板

每次新实验都在本目录创建一个 Markdown 文件，命名格式：

```text
YYYY-MM-DD-short-name.md
```

## 模板

```markdown
# 实验名称

## 基本信息

- 日期：
- 基准版本：
- 实验路线：
- 负责人：

## 问题来源

说明这个实验要解决什么问题。最好来自交易事件分析，而不是主观猜测。

## 理论假设

用一句话说明交易假设。例如：

> 高质量二类买卖点在确认前不应快速触及结构失效位，并且应更接近原中枢边界。

## 不允许改动

- 不改 third_confirmed 后 15m opposite_bsp 出场。
- 不改主标签定义，除非本实验专门研究标签。
- 不直接读取未来标签做回测决策。

## 允许改动

- 列出本次允许修改的文件和函数。

## 实现步骤

1. ...
2. ...
3. ...

## 验证方式

- 编译检查：
- 单元测试：
- walk-forward：
- 交易事件分析：

## 成功标准

- 交易频率不低于基准的指定比例。
- 收益或回撤相对基准改善。
- `realtime_invalid_before_confirm` 亏损贡献下降。
- `third_confirmed` 盈利路径不被破坏。

## 失败清理

- 删除实验代码。
- 删除临时结果目录。
- 只在 `ML/EXPERIMENT_LOG.md` 留结论。
```
